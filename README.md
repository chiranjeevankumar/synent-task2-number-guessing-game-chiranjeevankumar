Number Guessing Game

Description

This is a simple beginner-level Python game. The computer randomly selects a number between 1 and 100, and the player tries to guess it.

Features

- Generates a random number between 1 and 100
- Tells the player if the guess is too high or too low
- Counts the total number of attempts
- Displays a congratulatory message when the player guesses correctly

Technologies Used

- Python 3
- Google Colab (for development and testing)

How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

python number_guessing_game.py

Example Output

Welcome to the Number Guessing Game!
Guess a number between 1 and 100.
Enter your guess: 30
Too low! Try again.
Enter your guess: 70
Too high! Try again.
Enter your guess: 50
Congratulations! You guessed the number!
The correct number was: 50
Total attempts: 3

Note: The secret number is randomly generated, so the actual output may differ.
